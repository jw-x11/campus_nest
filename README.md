# Campus Nest

Campus Nest is a student-focused marketplace for renting unused space as storage. People with a spare closet, shelf, garage, basement, or room can list it, and people who need a place for their belongings for over summer can find somewhere nearby and cheaper than a commercial unit. 

## Features

- List a spare closet, shelf, garage, basement, or room.
- Search for storage by place, dates, and price.
- Book a listing for the dates you need.
- Browse listings on a map (in progress).
- Message the host or renter (in progress).
- Pay for a booking in the app (in progress).
- Leave a review after the rental (in progress).

## Tech stack

- React
- FastAPI
- PostgreSQL
- Redis
- SeaweedFS
- Mapbox for maps (in progress)
